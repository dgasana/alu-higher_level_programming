The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

MyList is a subclass of list:

    >>> issubclass(MyList, list)
    True

An empty list prints as empty:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

Unsorted list is printed sorted, without changing the original:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Negative numbers:

    >>> my_list = MyList([3, -1, 0, -7])
    >>> my_list.print_sorted()
    [-7, -1, 0, 3]

Already sorted list:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

Single element:

    >>> my_list = MyList([9])
    >>> my_list.print_sorted()
    [9]

Duplicate elements:

    >>> my_list = MyList([2, 2, 1, 1])
    >>> my_list.print_sorted()
    [1, 1, 2, 2]

print_sorted returns a new list each time:

    >>> my_list = MyList([3, 1])
    >>> my_list.print_sorted()
    [1, 3]
    >>> my_list
    [3, 1]
