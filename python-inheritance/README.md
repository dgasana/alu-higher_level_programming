# Python - Inheritance

Exercises on class inheritance in Python: `dir`, `type`, `isinstance`, subclassing built-ins, and a `BaseGeometry` → `Rectangle` → `Square` hierarchy.

| File | Description |
| --- | --- |
| `0-lookup.py` | Returns the list of attributes and methods of an object |
| `1-my_list.py` | `MyList` inherits from `list` and adds `print_sorted()` |
| `2-is_same_class.py` | True if an object is exactly an instance of a class |
| `3-is_kind_of_class.py` | True if an object is an instance of a class or its subclass |
| `4-inherits_from.py` | True if an object's class inherited from a class |
| `5-base_geometry.py` | Empty class `BaseGeometry` |
| `6-base_geometry.py` | `BaseGeometry` with an unimplemented `area()` |
| `7-base_geometry.py` | Adds `integer_validator(name, value)` |
| `8-rectangle.py` | `Rectangle` inherits from `BaseGeometry` |
| `9-rectangle.py` | `Rectangle` with `area()` and `__str__` |
| `10-square.py` | `Square` inherits from `Rectangle` |
| `11-square.py` | `Square` with its own `__str__` |
| `tests/` | Doctest files for tasks 1 and 7 |
