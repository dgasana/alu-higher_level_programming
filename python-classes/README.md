# python-classes

Introduction to classes and objects in Python: private attributes,
properties (getters/setters), and validation.

| File | Description |
|------|-------------|
| `0-square.py` | Empty class `Square` |
| `1-square.py` | `Square` with a private `size` attribute |
| `2-square.py` | `size` validation (`TypeError` / `ValueError`) |
| `3-square.py` | Adds the `area()` method |
| `4-square.py` | Adds `size` property getter and setter |
| `5-square.py` | Adds `my_print()` to print the square with `#` |
| `6-square.py` | Adds a validated `position` attribute used by `my_print()` |
