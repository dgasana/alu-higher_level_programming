# Python - Input/Output

Exercises on reading and writing files, JSON serialization, and turning class instances into dictionaries and back.

| File | Description |
| --- | --- |
| `0-read_file.py` | Reads a UTF8 text file and prints it |
| `1-write_file.py` | Writes a string to a file and returns the number of characters written |
| `2-append_write.py` | Appends a string to a file and returns the number of characters added |
| `3-to_json_string.py` | Returns the JSON representation of an object |
| `4-from_json_string.py` | Returns the object represented by a JSON string |
| `5-save_to_json_file.py` | Writes an object to a file as JSON |
| `6-load_from_json_file.py` | Creates an object from a JSON file |
| `7-add_item.py` | Adds command-line arguments to a list saved in `add_item.json` |
| `8-class_to_json.py` | Returns the dictionary description of an object |
| `9-student.py` | `Student` class with `to_json()` |
| `10-student.py` | `Student.to_json(attrs=None)` with attribute filtering |
| `11-student.py` | Adds `reload_from_json(json)` |
| `12-pascal_triangle.py` | Returns Pascal's triangle of `n` rows |
