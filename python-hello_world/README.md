# 0x00. Python - Hello, World

Introductory exercises: running Python from a shell script, `print`,
f-strings, string slicing and concatenation.

| File | Description |
|------|-------------|
| `0-run` | Shell script that runs the Python file named in `$PYFILE` |
| `1-run_inline` | Shell script that runs the Python code in `$PYCODE` |
| `2-print.py` | Prints a quoted sentence |
| `3-print_number.py` | Prints an integer with an f-string |
| `4-print_float.py` | Prints a float with 2 digits of precision |
| `5-print_string.py` | Prints a string 3 times, then its first 9 characters |
| `6-concat.py` | Concatenates two strings |
| `7-edges.py` | Slices the first 3, last 2 and middle letters of a word |
| `8-concat_edges.py` | Builds a sentence by slicing a string |
| `9-easter_egg.py` | Prints The Zen of Python |
