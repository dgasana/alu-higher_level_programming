# Python - More Classes and Objects

This project builds a `Rectangle` class step by step to practice object-oriented programming in Python.

| File | Description |
| --- | --- |
| `0-rectangle.py` | Empty class `Rectangle` |
| `1-rectangle.py` | Private `width` and `height` with property getters and validated setters |
| `2-rectangle.py` | Adds `area()` and `perimeter()` methods |
| `3-rectangle.py` | Adds `__str__` to print the rectangle with `#` |
| `4-rectangle.py` | Adds `__repr__` so `eval()` can recreate the instance |
| `5-rectangle.py` | Prints `Bye rectangle...` when an instance is deleted |
| `6-rectangle.py` | Adds the class attribute `number_of_instances` |
| `7-rectangle.py` | Adds the class attribute `print_symbol` |
| `8-rectangle.py` | Adds the static method `bigger_or_equal(rect_1, rect_2)` |
| `9-rectangle.py` | Adds the class method `square(cls, size=0)` |
