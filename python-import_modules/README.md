# 0x02. Python - import & modules

Exercises on importing functions and variables from modules, using
`sys.argv`, and keeping code from running on import with
`if __name__ == "__main__":`.

| File | Description |
|------|-------------|
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |
| `1-calculation.py` | Uses `add`, `sub`, `mul`, `div` from `calculator_1.py` |
| `2-args.py` | Prints the number of arguments and the list of arguments |
| `3-infinite_add.py` | Prints the sum of all arguments |
| `4-hidden_discovery.py` | Prints the names defined by the compiled module `hidden_4.pyc` |
| `5-variable_load.py` | Imports and prints the variable `a` from `variable_load_5.py` |

Helper modules: `add_0.py`, `calculator_1.py`, `variable_load_5.py`.

All scripts are written for Python 3 and follow the PEP 8 style (`pycodestyle`).
